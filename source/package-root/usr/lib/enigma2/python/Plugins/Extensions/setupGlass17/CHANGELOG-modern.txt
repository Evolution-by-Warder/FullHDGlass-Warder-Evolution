FullHDGlass17 9.51-modern2 (2026-09-12)
- Replaced broken Enhanced Weather AccuWeather HTML scraping with Open-Meteo JSON API.
- Enhanced Weather no longer depends on BeautifulSoup or an API key.
- Added Open-Meteo geocoding for Enhanced Weather city search and automatic migration of old city entries.
- Added current conditions and 9-day forecast: apparent temperature, humidity, pressure, visibility, wind, UV, sunrise and sunset.
- Replaced legacy AccuWeather condition parsing with WMO weather-code mapping to FullHDGlass17 icons.
- Removed MSN as a selectable weather provider; weather.service.msn.com is retired.
- Switched OpenWeatherMap current-weather calls from HTTP to HTTPS, including the duplicated plugin.py weather path.
- Weather errors are now written to the FullHDGlass17 log instead of silently leaving a blank Enhanced Weather screen.
