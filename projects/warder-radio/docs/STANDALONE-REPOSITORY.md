# Warder Radio moved to its own repository

Active source, tests, releases and future updates: https://github.com/Evolution-by-Warder/Radio-Warder-Evolution

This directory is the retained legacy development archive. Its radio testing feed remains available to installed test2–test6 updaters and offers a verified migration package. The bridge copies the exact standalone IPK to the legacy release URL and verifies it before advancing the feed. After installation and GUI restart the new package reads the standalone repository feed. Test1, which has no updater, needs a manual upgrade.

The FullHDGlass skin's stable releases and production feed are independent of this migration.
