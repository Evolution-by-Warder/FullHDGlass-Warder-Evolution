# Warder Radio development moved

The active source, tests, CI, IPK releases and new update feeds are at https://github.com/Evolution-by-Warder/Radio-Warder-Evolution . This old development directory is retained as an archive.

The dedicated migration workflow publishes byte-identical verified radio IPKs at the legacy URLs and then advances this archive's radio testing manifest. The previous radio-build workflow has been retired to prevent it rebuilding an archived version and replacing the migration feed. FullHDGlass skin production workflows and stable updates are independent.
