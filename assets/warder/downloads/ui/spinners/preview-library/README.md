# Warder — spinnery na výber

Rozbaľte celý archív a otvorte index.html. Ukazuje vždy jednu animáciu; prechádzať môžete tlačidlami Predchádzajúci/Ďalší alebo výberom názvu.

Každý spinner má vlastný pomenovaný adresár s preview.gif, snímkami vo frames/, vlastnou ukážkou index.html a údajmi o autorovi a zdroji. SpinKit obsahuje úplnú licenciu MIT. Neuvedené autorstvo ani licencie komunitných archívov nie sú domýšľané.

Duplicity sú evidované v community/catalog.json a pôvodné archívy zostávajú zachované bez úprav. Zatiaľ iba ukážky, bez nového IPK.
