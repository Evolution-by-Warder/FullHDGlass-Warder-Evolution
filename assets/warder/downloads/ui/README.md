# UI asset packs

Clean Warder layout for downloadable FullHDGlass interface resources.

- `help/` — setup/help screen images
- `menu-icons/` — standard menu icon pack
- `menu-icons-big/` — large menu icon pack
- `extra-screens/` — ExtraScreens graphics
- `icon-set-previews/` — icon set preview/additional icon pack
- `channel-selection-big/` — large ChannelSelection/provider graphics

The binary ZIP payloads are tracked by `../../assets-manifest.json`.
