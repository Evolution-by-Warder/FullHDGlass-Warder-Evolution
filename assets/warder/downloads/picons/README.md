# Picons

Clean Warder layout for downloadable picon-related asset packs.

- `providers/black/`
- `providers/white/`
- `providers/220x132/`
- `satellites/black/`
- `satellites/white/`
- `satellites/220x132/`
- `cam/black/`
- `cam/white/`

The binary ZIP payloads are tracked by `../../assets-manifest.json` and are intended to be published as release/download assets without modifying their original bytes.
