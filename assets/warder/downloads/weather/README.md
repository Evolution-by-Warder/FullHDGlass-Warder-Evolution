# Weather assets

Clean Warder layout for downloadable weather graphics.

- `icons/` — original static weather icon pack
- `icons-alt/` — alternate/newer static weather icon pack
- `info/black/` — black weather info picons
- `info/white/` — white weather info picons
- `animated/` — animated weather icon pack

The binary ZIP payloads are tracked by `../../assets-manifest.json`.
