# FullHDGlass – Warder Evolution 1.0.77

## Offline factory reset and clearer settings

Reset all restores the original **148 bundled icons** (icon type 1) directly from the installation, without downloading or requiring any optional icon pack, including when type 1 is already selected. The factory assets are included in the package and checked for completeness.

The storage menu now explains the location of downloaded graphics sets, picons and other skin data. Its help is separate from the backup configuration file `hdg17.conf` help. New labels, help text and reset errors are localized to supported OSD languages.

The obsolete MSN weather-provider default was removed to prevent a reset warning.

## Lossless graphic optimization

15 large PNG assets, including DAB+ information, the radio no-cover graphic, settings backdrop and menu images, were optimized without changing decoded pixels, dimensions or transparency. The source artwork footprint is reduced by **686,901 bytes** (about 671 KiB), more than the 380,509 bytes of bundled factory icon backups.

## Compatibility

Existing radio graphics and the radio-background JPEG are retained. OpenATV, OpenPLi, Prime Time and EPG paths are otherwise unchanged. Restart the Enigma2 GUI after installation.
