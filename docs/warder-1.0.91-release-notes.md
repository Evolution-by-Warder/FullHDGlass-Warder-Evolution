# FullHDGlass – Warder Evolution 1.0.91

- Bezpečnejší životný cyklus časovačov a natívnych textových prvkov pri skrytí a zatvorení okna.
- Opravené podmienené zdroje tlačidiel QuickMenu a InformationNetwork podľa hlásenia OpenATV 8.1.
- Zachované existujúce nastavenia, grafika, picony a predchádzajúce opravy. Po inštalácii reštartujte Enigma2.

Ochrany sú preventívne; príčina natívneho C++ pádu zo zaslaného crashlogu nie je jednoznačne potvrdená.
