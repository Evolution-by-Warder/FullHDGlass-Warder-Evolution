# Pomocné balíky FullHDGlass

Jediné pracovné úložisko je `assets/warder/downloads/`. Spoločný katalóg je `assets/warder/downloads.json`. Aktualizácie grafiky menia príslušný archív a jeho kontrolné údaje v katalógu.

| Obsah | Cesta pod spoločným úložiskom |
|---|---|
| Grafická nápoveda | `ui/help/g17_setup_pict.zip` |
| Sady ikon a ukážky | `ui/icon-set-previews/more_icons.zip` |
| Náhľady informačných panelov | `ui/icon-set-previews/warder-infobar-types.zip` |
| Extra obrazovky | `ui/extra-screens/extraScreens17.zip` |
| Menu ikony | `ui/menu-icons/`, `ui/menu-icons-big/` |
| Počasie | `weather/` |
| Picony | `picons/` |

Releases obsahujú inštalačné IPK a kontrolné súčty. GitHub zároveň automaticky zobrazuje odkazy na zdrojový ZIP/TAR; tie nie sú ručne priložené pomocné balíky.

Od 1.0.42 používa aj samostatný sťahovač náhľadov spoločné úložisko. Staršie inštalácie musia aktualizovať skin, aby použili nové adresy; existujúca overená cache funguje ďalej. Zvolené úložisko `hdg17_files` v prijímači sa nemení.

Pôvodné vývojové balíky a prílohy Releases sa odstránia až po overení verejných archívov a aktívnej aktualizácie 1.0.42. Záznam: `reports/auxiliary-assets-consolidation-20261030.json`.
