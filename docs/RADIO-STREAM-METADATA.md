# Internet radio song metadata and album covers

Owner-directed integration, 27 October 2026. The functional reference was HDF Radio 2.28.0 (koivo & oerlgrey), distributed as GPL-2.0-or-later according to the supplied IPK control. Reference package SHA256: `196475c733147d02cf97d07145090d62e2be3eec64581d5417a6382755dd2203`.

Static inspection found StreamMetadataMonitor, MetadataStreamProtocol, artist/song parsing, cover search, and a separate YouTube player. The selected Warder scope is metadata and album artwork only. This is an independent implementation using the existing OpenATV service metadata interface and standard ICY metadata; no HDF binaries or extracted implementation code are redistributed.

The shared metadata reader first uses sTagArtist/sTagTitle from the current radio service, then a bounded ICY lookup if no usable pair is available. Only explicit HTTP(S) radio references are eligible, never TV streams. Existing decoded URL query escapes are preserved. The artwork renderer retains its RDS and native DAB MOT paths and existing strict catalogue matching. No arbitrary title-only cover is accepted. The existing RadioText label is updated only for internet radio; RDS text ownership and every XML coordinate/image remain unchanged.

A single background worker is shared by text and artwork. It reads at most 256 KiB of audio to reach one metadata block (at most 4080 bytes), uses a three-second socket timeout, a six-second read deadline after headers, and checks no more frequently than every 15 seconds. Station ownership/generation discards late results. Cover network requests stay in the existing separate background lookup. Metadata is not logged. Stream URLs, credentials and listening histories are not sent to the cover catalogue; only the current artist and song are used by the existing artwork search. A failed lookup preserves the existing neutral cover fallback. Legacy Shoutcast servers that return a non-HTTP ICY status line may require native player tags; this fallback expects an ordinary HTTP response carrying icy-metaint.

`python3 tools/test-radio-stream-metadata.py -v` checks native tags, encodings, apostrophes, truncation, size/time limits, nonblocking reads, shared-worker ownership, stale-cover rejection and scoped native-label updates. Live tests of three owner-provided Regiocast streams timed out from the build environment. Receiver playback and live metadata/cover acquisition must still be confirmed on the owner's box.

## Catalogue repair in 1.0.31

The lookup now queries the Slovak, Czech and US catalogues in that order, stopping on a verified artwork result. The former country-less query implicitly used the US catalogue and missed regional releases. Unicode decomposition removes combining accents for comparison only; original on-screen tags stay unchanged. Complete artist and track identities remain required under the existing controlled credit/version rules. The HDF screenshot for Katarína Knechtová / Život nás má rád displayed Protože to nevzdám, an unrelated track with that artist in a multi-artist credit; the negative regression test deliberately rejects it. Catalogue calls remain bounded and run in the existing single artwork worker. A failing catalogue does not prevent the next region from being searched.

## Artwork coverage in 1.0.32

Matching has not been relaxed to accept a guest rendition instead of the band recording. The user explicitly reconfirmed that merely finding the same performer is insufficient. If stores have no usable cover, MusicBrainz recording search supplies releases only after complete artist/title identity checks. Only approved front artwork from Cover Art Archive for that same release is accepted. MusicBrainz requests are serialized at >=1.1 seconds. Catalogue JSON reads are capped at 1 MiB; JPEG downloads at 4 MiB. All I/O remains in the existing artwork worker. Failed songs get at most one delayed retry (15 seconds), with station-generation ownership retained.

Primary API references: https://musicbrainz.org/doc/MusicBrainz_API and https://musicbrainz.org/doc/Cover_Art_Archive/API . Only current artist/title and release IDs are sent; no stream URLs, tokens or receiver credentials. The build-host MusicBrainz probe returned a Site Unavailable HTML response, while Cover Art Archive returned the approved front image manifest for release 64ea2902-76ff-489e-9a8d-0b285d5eff1d. Full receiver end-to-end validation remains pending.

Reversed station fields: the Europa 2 sample sent Uncovered Paradise - Ukitas. A live SK store query returned artist Ukitas, track Uncovered Paradise, album Uncovered Paradise - Single. The matcher accepts reversed fields only when both complete normalized catalogue fields match, with no partial-word or version fallback for reversal. Two regression tests cover the sample and reject partial artists/different versions.

Artwork stability: native tags and ICY may alternate Artist - Title and Title - Artist for the same track. The renderer retains the same in-station key for an exact reversal of the current complete pair. Incomplete metadata has a five-second grace period only within the same service; new complete track data or a service change clears the previous cover immediately. Decoder callbacks carry their owning decode-generation token (without retaining obsolete decoder objects) and stale completions cannot clear the newer decoder. Five regressions cover order alternation, brief/long gaps, real song changes, station changes and late decoder ownership.

## Complete collaboration credits in 1.0.33

The Fun Radio Dance sample publishes artist `Nervo, B Jones, Eke` and title `Wherever You Go`; the live SK, CZ and US store queries returned `NERVO & B Jones` / `Wherever You Go (feat. EKe)`. A new controlled comparison combines a declared featured credit with the main artist roster and compares complete normalized names, including every guest, and the complete base title. It is only used when at least one side declares a featured credit. Commas and collaboration separators are normalized for this full-roster comparison only; existing lead-artist helpers are unchanged. Different guests, missing guest names, partial artist names and different base titles/remixes fail this rule. The earlier Robo Grigorov & Midi vs Kristina guest rendition remains rejected. Four regression tests extend the suite from 50 to 54 tests.
