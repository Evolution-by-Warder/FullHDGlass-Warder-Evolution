# FullHDGlass – Warder Evolution 1.0.75

## Channel Selection performance
- Native Enigma2 channel-list EPG drawing is now the default for smooth navigation, confirmed to be substantially faster on Octagon SF8008 with OpenATV 8.0.1.
- A new **Scroll EPG titles** switch in **Settings → Channel Selection** optionally enables the extended EPG-title clipping and marquee renderer in the standard ChannelSelection.
- **Default: OFF**. Previously generated overlays are removed on the next settings application, restoring the native list.
- PIG variants, Prime Time, channel picons, font settings and existing progressbars are preserved.
- Short setting labels are localized for Slovak, Czech, English, German, Polish, Hungarian, Russian, French, Italian and Spanish.
- Restart GUI to activate the setting.

This release builds upon stable 1.0.74, including the Plugin Browser top-edge fix.

**Installation:** use the official IPK package; restart Enigma2 GUI after installing.
